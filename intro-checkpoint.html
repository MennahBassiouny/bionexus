Introduction Checkpoint: Are You Ready for Track 1?

Ten friendly questions on the big ideas from the Introduction: how DNA, RNA and protein connect, what bioinformatics questions look like, and your first lines of code. Take it before Track 1 to see what you already understand.

Track checkpoint ~20 min In your browser, no code

What this checks

  • You can explain how DNA, RNA and protein connect.
  • You can recognise a bioinformatics question.
  • You can read a few lines of simple Python and fix a common error.
  • You know why scripts and packages matter.

Before you start

  • Finish the Introduction lessons on the roadmap. No coding experience is needed beyond the first Python lesson.
  • No notes on the first try. The point is to find out what you can recall, which is also one of the best ways to make it stick.

How this checkpoint works

Answer all ten questions. When you finish, the page shows your score. 7 of 10 counts as a pass; aim for 8 or more before moving on. Every explanation links to the lesson to review.

This is a self-check, not an exam. The answers live in the page, so it only works if you answer honestly before reading the explanation. If you score below 7, review the linked lessons, wait a day or two, then reload and try again. Coming back after a break helps you remember more than re-reading straight away.

The ten questions

Scenario questions. Pick the best answer; some wrong answers are tempting on purpose.

A gene's DNA has a single-letter change. Why might the protein made from that gene change too?
This is the central dogma: DNA is copied into RNA, and RNA is read to build protein (Crick 1970). A change in the DNA is copied into the RNA, and it can change which amino acid is used. Some changes do not alter the protein, for example when the new three-letter code still means the same amino acid, or when the change falls outside the protein-coding part of the gene. Review: The biology a coder needs.
A gene is copied from DNA into RNA, and the RNA is then used to build a protein. What are these two steps called?
Transcription copies a gene's code into RNA, like loading a function into memory; translation reads the RNA to build the protein, like running it (Crick 1970). Review: The biology a coder needs.
Humans have about 20,000 genes that make proteins. Which statement is also true?
Not every gene ends in a protein. Many genes produce RNAs that work on their own, which is one reason the genome holds far more than protein code (GENCODE). Review: The biology a coder needs.
Which of these is a bioinformatics question?
Bioinformatics uses computers to answer biological questions from data. The other options are wet-lab or purchasing questions, though their answers can affect the data you later analyse. Review: What bioinformatics actually is.
Why write your analysis as a script instead of doing every step by clicking in a spreadsheet?
Clicks leave no record, so nobody can repeat or check them. A script is like a written lab protocol: it can be rerun, reviewed and reused (Wilson et al. 2014). Scripts can still have bugs, which is why they are worth checking. Review: The computing a biologist needs.
What does this Python code print?
dna = "ATGCGC"
print(dna.count("G") / len(dna))
There are 2 G's in 6 letters, so 2 / 6 = 0.333... Note this is the G fraction only. GC content would count G and C together: (2 + 2) / 6 = 0.666... Review: Your first 10 lines of Python.
Your Python cell shows the red error NameError: name 'dna' is not defined. What is the most likely cause?
A NameError means Python has never seen that name in this session. Run the cell that defines it first, or check the spelling. In notebooks, running cells out of order is the most common cause. Review: Help and FAQ (my cell turned red).
You need to read FASTA files in Python. What is usually the best first approach?
A package is shared, tested code for a common job. Reusing it saves time and avoids edge-case bugs that a quick home-made reader would miss (Cock et al. 2009). Review: The computing a biologist needs.
A biologist says gene X is "highly expressed" in liver. What would you expect to see in liver RNA-seq data?
Expression means a gene is being copied into RNA. RNA-seq counts reads from each gene's RNA, so a highly expressed gene produces many reads. Nearly every cell has the same DNA; what differs is which genes are expressed. Review: The biology a coder needs.
Roughly how many DNA letters are in one copy of the human genome?
About 3 billion bases (the complete T2T assembly is about 3.05 billion; Nurk et al. 2022). That scale is why biology needs computers: no one can read it by hand. Review: The biology a coder needs.
