Project: Explore a Real Dataset with R

Take a real, published dataset from messy to insight: load it, clean it, summarise it by group, and produce a polished figure - the exact workflow you'll later run on gene expression data.

🟢→🟡 Beginner project ⏱️ ~1.5 hr 📊 R · tidyverse 📈 Real data

Before you start

  • Finish R: Level 1 (Basics). Level 2 is optional: everything new here is explained as you go.
  • No install needed: every step runs in your browser. In RStudio, you need the tidyverse and palmerpenguins packages (see Installing R and RStudio, Step 4).
  • Any term new? The Glossary has it.

Learning objectives

By the end of this lesson you will be able to: load a real published dataset; clean it; summarise it by group; and produce a polished figure.

We'll use the Palmer Penguins dataset - real measurements of 344 penguins from three species, measured on three islands near Palmer Station in Antarctica (2007 to 2009). It's deliberately friendly to start on, but every move you make here is the same move you'll make on a gene expression table: load, inspect, clean, group, summarise, plot. Learn the pattern on penguins, apply it to biology.

Why not jump straight to gene data?

Because the skill you're building - wrangling a real table and seeing structure in it - is identical, and penguins won't drown you in biological jargon while you're still learning the verbs. Once this clicks, swapping in an expression matrix is a small step.

Do the whole project in your browser

Each step has a dark R box: press Run, in order from Step 1, because each step uses what the one before created. The first Run downloads R and the packages, so allow a minute or two on a slow connection. Doing it in RStudio instead? Copy the same code into a script.

1Load the data and look at it

Always look before you leap. glimpse() shows you the columns (species, island, bill length, flipper length, body mass, sex…) and their types. Notice some values are NA - missing. Real data is always a little messy.

Seeing "Column `bill_length_mm` doesn't exist" or "object 'bill_length_mm' not found"?

R 4.5 and newer comes with its own copy of the penguins data, with shorter column names (bill_len, bill_dep, body_mass). If you forget library(palmerpenguins), R uses that copy and the column names in this project will not match. Run the library(palmerpenguins) line, then try again.

2Clean it

Decode the jargon: NA

NA means "not available" - a missing value. Many calculations return NA when any value is missing (on purpose, so you don't get silently wrong answers). Deciding what to do with them is a real and important judgment call in every analysis.

3Summarise by group

This is the question-answering step. How do the species differ?

In one short block you've just computed, per species, how many penguins there are and their average measurements. That group_by() |> summarise() combination is one of the most useful patterns in all of data analysis.

4Visualize the structure

Look at the result: the three species form distinct clusters. You've just discovered something real from data - that bill shape alone largely tells the species apart. Seeing group structure in measurements is the intuition behind clustering gene expression later, where the computer finds such groups without being told the labels.

5One more: a boxplot

🚀 Make it your own

  • Use filter() to look at just one island, then re-make the scatter plot. Do the clusters change?
  • Add facet_wrap(~ island) to the scatter plot - what does splitting by island reveal?
  • Group by species and sex together and compare average body mass. Which is the bigger driver? (A few penguins have no recorded sex, so you will see an NA group; decide whether to drop it.)
  • Bridge to biology: read our small practice gene table with read.csv("https://bionexushub.com/practice-genes.csv") and run the same load → inspect → group → plot pattern. For example, plot length_kb against expression, or summarise the mean expression per chromosome. The skill transfers directly.
  • Portfolio move: turn your script into an HTML report (in RStudio: File → Compile Report, or Ctrl/Cmd+Shift+K) and put it on GitHub.

What you just did

You took a real, imperfect dataset and walked the full loop: load → inspect → clean → summarise → visualize. You handled missing data, computed group summaries, and made two figures that reveal genuine structure. That is data analysis - and it's the identical workflow behind a published RNA-seq figure, just with genes in place of penguins.

Why na.rm = TRUE inside mean()?

It tells mean() to ignore missing values when averaging. Without it, a single NA in the column makes the whole result NA - R's way of refusing to guess.

Check your understanding

The R project analyzes which friendly real dataset?
The project uses Palmer Penguins: 344 real penguins from three species, a friendly table for practising the same steps you will use on gene expression data.
Computing a value per group (like the mean per species) is called:
group_by() splits the rows by species and summarise() collapses each group to one value, such as a mean.
Why does the lesson start you on penguins instead of gene expression data?
The wrangling skill is the same on penguins as on an expression table; penguins just let you learn the steps without extra jargon, then the skill transfers.
What does NA mean in the penguins dataset?
NA marks a missing value; many calculations return NA when any value is missing, so you do not get silently wrong answers, which is why the project drops or handles them.
Which function in the project draws the scatter and box plots?
The project builds its figures with ggplot(), adding layers like geom_point() and geom_boxplot() to reveal the structure in the data.
